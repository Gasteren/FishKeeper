# FishKeeper

Retail fishing tracker for **Midnight**. Counts every catch, lists what you hooked, and prices the haul with __**TradeSkillMaster.**__ See Gallery for more images / examples.

A compact bar while you fish. Expand it when you want the full list. Timer starts on your first cast.

## Features

- Compact fishing bar: catch count, session timer, gold, last fish
- Expanded list with quantity, drop %, and value
- TSM prices: **Region avg** or **Min buyout** (vendor sell as fallback)
- Grey items always use vendor sell
- Gold per hour and catches per hour on hover
- Session timer with pause / start; confirmed reset
- Patient Treasure chest loot is tracked and tagged `[chest]`
- **The Coiled Huntress** venom, only while that pole is equipped
- **Midnight Angler's Grand Line** on / off (only when you have it enchanted)
- Announce catches replaces default fishing loot chat (see gallery)
- Six themes: Steel, Gold, Night, Horde, Alliance, Simple
- Optional auto-compact when you start fishing

**TradeSkillMaster is optional**. Without it, FishKeeper uses vendor sell prices.

## Commands

There is a options menu or use the following commands:

`/fk` toggle window  
`/fk compact` compact / expanded  
`/fk pause` pause / resume timer  
`/fk price` toggle Region / Min BO  
`/fk session` reset this session  
`/fk theme` cycle theme  
`/fk lock` lock the window  
`/fk help` full command list
